# Solara Bay

An original open-world crime game built for the [make.fun "Make GTA 6" competition](https://make.fun/bounty/gta6-01).

Explore the city of Solara Bay on foot and by car: traffic and pedestrians, cars to steal and drive, a wanted level with police who respond to it, missions and a story, combat, and a HUD with a minimap. Everything — city, characters, vehicles, names, story, art and sounds — is original; nothing is taken from Rockstar Games' Grand Theft Auto series or any other commercial game.

## Play

The game is static files under `game/` with no build step. Serve it with any static HTTP server and open `game/index.html` in desktop Chrome:

```sh
node serve.ts
```

then open http://localhost:8080. Keyboard and mouse controls.
